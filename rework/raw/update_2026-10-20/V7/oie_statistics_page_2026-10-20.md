Item: V7 (revision of 20 October 2026). ## 1. OIE statistics page (the page that links the per-product files)

- URL: https://www.oie.go.th/view/1/statistics/TH-TH
- Date read: 20 October 2026.
- Page title: สถิติอุตสาหกรรม (Industrial Statistics). Publisher line: สำนักงานเศรษฐกิจอุตสาหกรรม กระทรวงอุตสาหกรรม.
- What the page says the statistics cover (extract of the page text): production volume, sales volume, sales value, finished-goods inventory and production capacity. The page says the data come from a survey of a sample of manufacturers and are mainly used to compile the industrial index.
- Coverage rule, quoted as returned: "รายงานสถิตินี้จะแสดงผลข้อมูลสถิติ เฉพาะผลิตภัณฑ์อุตสาหกรรมที่สามารถจัดเก็บได้ตั้งแต่ 5 โรงงานขึ้นไป". Team translation: this statistical report shows only industrial products for which data can be collected from 5 or more factories.
- Three datasets are offered:
  1. January 2543 (2000) to December 2558 (2015), labelled "เดิม" (previous), a ZIP archive.
  2. January 2559 (2016) to December 2563 (2020), labelled "เดิม" (previous), an Excel file.
  3. January 2564 (2021) to the present, an Excel file and a CSV file. The page says the industrial index base year changed to 2564 (2021), which is why the framework was adjusted. The latest file is for August 2569 (August 2026).
- The page does not describe each product table separately in the extract. Whether the files contain a row for carbonated soft drinks is not known, because no file was opened.

None of the four files was downloaded. A download needs the user's permission. File sizes were not checked.
